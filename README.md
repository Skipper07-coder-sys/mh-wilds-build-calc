# mh-wilds-build-calc

Monster Hunter Wilds build finder and damage calc: max-DPS builds compared against the current meta.

- `builds/` holds build write-ups (Markdown) with the damage maths, uptime caveats and Math Hunter links.
- `tools/` holds the search script used to generate them.

Game version: TU4 / v1.041 (latest content patch as of 2026-10).
